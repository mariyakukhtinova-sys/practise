# Парсер книжного магазина Books to Scrape

## Цель проекта

Проект предназначен для сбора данных о книгах с сайта [Books to Scrape](http://books.toscrape.com/). 
Основные функции включают:
- Парсинг каталога книг с получением ссылок на страницы книг
- Сбор детальной информации о каждой книге
- Автоматизированный запуск по расписанию
- Тестирование ключевых функций парсера

## Инструкции по запуску

### Запуск парсера
Запуск основного скрипта запустит процесс, который будет
обновлять данные по расписанию - каждый день в 19:00
```python scraper.py```

### Запуск тестов
```pytest tests/tests_scraper.py```
